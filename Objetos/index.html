Objetos em JavaScript

Em JavaScript, objetos são coleções de propriedades. Cada propriedade é uma chave e um valor.
Objetos permitem agrupar dados relacionados e funções que operam nesses dados.

Exemplo de objeto

const pessoa = {
  nome: 'Ana',
  idade: 28,
  profissao: 'Desenvolvedora',
  saudacao: function() {
    return `Olá, meu nome é ${this.nome}`;
  }
};

console.log(pessoa.nome);        // Ana
console.log(pessoa.idade);       // 28
console.log(pessoa.saudacao());  // Olá, meu nome é Ana

Acessando e alterando propriedades

Você pode acessar propriedades com pessoa.nome ou pessoa['nome']. Também pode adicionar ou atualizar valores.

pessoa.idade = 29;
pessoa.email = 'ana@email.com';

console.log(pessoa.idade); // 29
console.log(pessoa.email); // ana@email.com

Objetos como parâmetros

Funções podem receber objetos e usar suas propriedades.

function apresentar(usuario) {
  return `Nome: ${usuario.nome}, Profissão: ${usuario.profissao}`;
}

console.log(apresentar(pessoa));

Resumo

Objetos são estruturas fundamentais em JavaScript. Eles permitem representar entidades reais com propriedades e métodos, facilitando a organização e reutilização de código.
