Template Strings

O que são Template Strings?

Template Strings são uma forma de trabalhar com strings em JavaScript usando crase (`) em vez de aspas. Elas permitem interpolação de variáveis e expressões.

Exemplo 1: Interpolação Básica


            const nome = "João";
            const idade = 30;
            
            const mensagem = `Olá, meu nome é ${nome} e tenho ${idade} anos.`;
            
            console.log(mensagem); // Saída: Olá, meu nome é João e tenho 30 anos.

Neste exemplo, usamos `${}` para inserir as variáveis `nome` e `idade` dentro da string.

Exemplo 2: Expressões


            const a = 10;
            const b = 5;
            const resultado = `A soma de ${a} + ${b} é ${a + b}`;
            console.log(resultado); // Saída: A soma de 10 + 5 é 15

Neste exemplo, usamos `${}` para inserir expressões dentro da string.

Exemplo 3: Strings Multilinhas


            const multilinhas = 
            `Linha 1
            Linha 2
            Linha 3`;
            console.log(multilinhas);

Neste exemplo, usamos crases para criar strings multilinhas.

Exemplo 4: Funções com Template Strings


            function saudacao(usuario) {
                return `Bem-vindo, ${usuario}! Seu acesso foi registrado.`;
            }
            const usuario = "Maria";
            const msg = saudacao(usuario);
            console.log(msg);

Neste exemplo, usamos template strings dentro de uma função para criar uma mensagem de saudação personalizada.

Conclusão

Template strings são uma ferramenta poderosa em JavaScript que facilitam a manipulação de strings e a interpolação de variáveis e expressões.
