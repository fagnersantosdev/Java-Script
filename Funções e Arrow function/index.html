Funções e Arrow Function

Funções

As funções são blocos de código que podem ser reutilizados em diferentes partes do programa. Elas podem receber parâmetros e retornar valores. A sintaxe básica para declarar uma função é:

function nomeDaFuncao(parametro1, parametro2) {
    // código a ser executado
    return valor;
    }

Arrow Function

A Arrow Function é uma forma mais concisa de escrever funções em JavaScript. Ela utiliza a sintaxe de "seta" (=>) e não possui seu próprio contexto de "this". A sintaxe básica é:

const nomeDaFuncao = (parametro1, parametro2) => {
    // código a ser executado
    return valor;
    };
