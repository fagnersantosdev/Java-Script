Default Parameters

Default Parameters ou Parâmetros Padrão são uma funcionalidade do JavaScript que permite definir valores padrão para os parâmetros de uma função. Isso significa que, se um argumento não for fornecido ao chamar a função, o parâmetro assumirá o valor padrão definido.

Exemplo de função com parâmetros padrão:


        function saudacao(nome = "Visitante") {
            return `Olá, ${nome}!`;
        }
        
        console.log(saudacao()); // Saída: Olá, Visitante!
        console.log(saudacao("João")); // Saída: Olá, João!

Como os Parâmetros Padrão Funcionam

Quando uma função é chamada, o JavaScript verifica se os argumentos foram fornecidos. Se um argumento não for passado, o valor padrão definido para aquele parâmetro será usado. Isso permite que as funções sejam chamadas com menos argumentos, tornando o código mais limpo e fácil de ler.

Mas eles fazem mesmo a diferença?

Sim, os parâmetros padrão fazem uma grande diferença na escrita e manutenção do código. Eles permitem que as funções sejam mais flexíveis e fáceis de usar, sem a necessidade de verificar se os argumentos foram passados. Num ponto de vista podemos até pensar que tanto faz ou é apenas algo para lembrar de passar os argumentos. Mas se não usarmos os parâmetros padrão, a função é definida como undefined e precisamos escrever mais código para lidar com valores indefinidos.

Por exemplo, sem parâmetros padrão:


        function calcularDesconto(preco, desconto) {
            return preco - desconto;
        }

        // O programador esqueceu de passar o valor do desconto!
        const valorFinal = calcularDesconto(100); 

        console.log(valorFinal); 
        // Resultado: NaN (Not a Number - Não é um número)
        // Por que? Porque o JavaScript tentou fazer: 100 - undefined
        }

Se esse NaN for parar na tela do usuário ou no banco de dados, você tem um bug chato para resolver. Antigamente, para evitar isso, nós tínhamos que encher o código de ifs (ex: if (desconto === undefined) { desconto = 0; }).

A solução: Default Parameters
O ES6+ trouxe os parâmetros padrão justamente para resolver isso de forma elegante. Você já define a "rota de fuga" direto na criação da função. 


        // Se ninguém passar o desconto, ele assume que é 0
        function calcularDesconto(preco, desconto = 0) {
            return preco - desconto;
        }

        const valorFinal = calcularDesconto(100); 

        console.log(valorFinal); 
        // Resultado: 100
        // O código continuou funcionando perfeitamente!

Contudo, vemos como é simples de entender o conceito de parâmetros padrão.
