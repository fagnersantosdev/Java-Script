Módulos e Classes

O JavaScript moderno (ES6+) trouxe dois conceitos muito importantes: módulos e classes.

Módulos: Permitem dividir o código em arquivos menores e reutilizáveis. Cada arquivo pode exportar funções, objetos ou valores, e outros arquivos podem importar esses módulos.

Classes: São uma forma de criar objetos com propriedades e métodos, facilitando a programação orientada a objetos.

Exemplo de Módulo

        
        // arquivo: mathUtils.js
        export function add(a, b) {
            return a + b;
        }

        export function subtract(a, b) {
            return a - b;
        }

Exemplo de Classe

        
        class Person {
            constructor(name, age) {
                this.name = name;
                this.age = age;
            }
            //O `constructor` é a função que roda automaticamente quando você cria uma "nova" pessoa a partir desse molde.

            greet() {
                console.log(`Hello, my name is ${this.name} and I am ${this.age} years old.`);
            }
        }

        const john = new Person('John', 30);
        john.greet();
