Spread Operator

Lembra do Rest Operator (que pega itens soltos e agrupa num array)? O Spread usa os mesmos três pontinhos (...), mas faz exatamente o inverso: ele pega um array ou objeto fechado e espalha (desempacota) o conteúdo dele em outro lugar.

Por que ele é tão famoso? (A regra de ouro do React)

No React, existe uma regra sagrada chamada Imutabilidade. Significa que você nunca deve alterar um dado original diretamente (não podemos fazer array.push() ou objeto.nome = "Novo" para atualizar a tela).

Em vez de alterar o original, você deve criar uma cópia exata, mudar o que precisa nessa cópia, e avisar o React: "Olha, essa é a nova versão dos dados". O Spread Operator é a ferramenta perfeita para fazer essas cópias!

Vamos ver como ele funciona na prática em Arrays e Objetos:
Imagine que você tem uma lista de compras e quer adicionar itens novos, mas sem modificar a lista original.

Jeito antigo de fazer:

        
            const frutas = ["Maçã", "Banana"];
            // O push altera a lista original. O React odeia isso!
            frutas.push("Laranja");

Com o spread operador

        
            const frutas = ["Maçã", "Banana"];

            // Lemos assim: "Crie um novo array, espalhe tudo o que tem em 'frutas' aqui dentro, e depois adicione 'Laranja'."
            const novasFrutas = [...frutas, "Laranja"]; 

            console.log(novasFrutas); // ["Maçã", "Banana", "Laranja"]
            console.log(frutas);      // ["Maçã", "Banana"] (O original continua intacto!)

Você também pode usar para juntar dois arrays facilmente: const misturado = [...array1, ...array2];

Spread Operador em Objetos

Essa é a utilidade máxima dele. Você quer copiar um objeto inteiro, mas alterar apenas uma única propriedade dele.

        
            const usuario = {
            nome: "Carlos",
            idade: 25,
            cidade: "São Paulo"
        };

        // Queremos fazer o aniversário do Carlos (mudar a idade para 26)
        // Lemos assim: "Crie um novo objeto, espalhe tudo do 'usuario' original, mas sobrescreva a 'idade' com 26."
        const usuarioAtualizado = {
            ...usuario,
            idade: 26 
        };

        console.log(usuarioAtualizado); 
        // Resultado: { nome: "Carlos", idade: 26, cidade: "São Paulo" }

O JavaScript é inteligente: se a propriedade idade já existia no objeto espalhado, ele apenas substitui pelo valor novo. O resto (nome e cidade) ele mantém igual.
