Descontruindo um Array

A desestruturação de arrays em JavaScript permite extrair valores de um array e atribuí-los a variáveis individuais de forma concisa.

Exemplo de desestruturação de um array

        
            const numeros = [1, 2, 3, 4, 5];

            const [primeiro, segundo, ...resto] = numeros;

            console.log(primeiro); // Resultado: 1
            console.log(segundo); // Resultado: 2
            console.log(resto); // Resultado: [3, 4, 5]

No exemplo acima, estamos desestruturando o array numeros e atribuindo os dois primeiros valores às variáveis primeiro e segundo, enquanto o restante dos valores é armazenado no array resto.
