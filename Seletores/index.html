O que são seletores?

No JavaScript puro (Vanilla JS), se você quer mudar a cor de um botão, trocar um texto ou fazer algo acontecer quando o usuário clica em algum lugar, você precisa primeiro "pesgar" (selecionar) esse elemento lá do HTML e trazer para dentro do JavaScript.

Existem vários métodos para isso, mas hoje em dia, nós focamos nos "Três Grandes":

    É o seletor mais clássico e rápido. Você usa quando o elemento HTML tem um id único.

    • No HTML:
    • No CSS: #meu-botao { color: blue; }
    • No JS: const botao = document.getElementById("meu-botao");

    É o seletor mais usado e versátil. Você usa quando o elemento HTML tem uma classe.

    • No HTML:
    • No CSS: .botao-principal { color: blue; }
    • No JS: const botaoPrincipal = document.querySelector(".botao-principal");

    É o seletor mais genérico. Você usa quando quer selecionar todos os elementos de um tipo específico.

    • No HTML: 
      Meu Site
    • No CSS: h1 { color: blue; }
    • No JS: const titulo = document.querySelector("h1");
