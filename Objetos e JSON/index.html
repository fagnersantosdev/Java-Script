Objetos e JSON

O JSON (JavaScript Object Notation) é o formato padrão de comunicação na internet.
Quando o seu frontend (React) conversa com o seu backend (Node), eles trocam dados no formato JSON.
Ele parece muito com um objeto JavaScript, mas no fundo é só um texto (string).
Para fazer essa ponte entre "objeto real no código" e "texto para enviar pela internet", usamos dois métodos essenciais:

  • JSON.stringify(): Pega um objeto JavaScript e transforma em uma string JSON (preparando para envio).

  • JSON.parse(): Pega uma string JSON recebida da internet e transforma de volta em um objeto JavaScript (preparando para uso no código).
        
        // Criando um objeto JavaScript
        const pessoa = {
            nome: "João",
            idade: 30,
            profissao: "Desenvolvedor"
        };

        // Exibindo o objeto no HTML
        document.getElementById('objeto').textContent = JSON.stringify(pessoa, null, 2);

        // Convertendo o objeto para JSON
        const pessoaJSON = JSON.stringify(pessoa);

        // Exibindo o JSON no HTML
        document.getElementById('json').textContent = pessoaJSON;
