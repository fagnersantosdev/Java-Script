Função Find

O que o Find faz?

O find é uma função que percorre um array e retorna o primeiro elemento que satisfaz a condição especificada em uma função de callback. Se nenhum elemento for encontrado, ele retorna undefined.

Exemplo de uso do Find

        
            const numeros = [5, 12, 8, 130, 44];

            const encontrado = numeros.find(elemento => elemento > 10);

            console.log(encontrado); // Resultado: 12

Como funciona:

        
            // O find percorre o array e verifica cada elemento:
            // Elemento 5: não satisfaz a condição (5 > 10) => continua
            // Elemento 12: satisfaz a condição (12 > 10) => retorna 12
