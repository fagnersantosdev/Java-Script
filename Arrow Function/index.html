Arrow Functions

As Arrow Functions são uma forma concisa de escrever funções em JavaScript. Elas foram introduzidas no ES6 e possuem uma sintaxe mais curta em comparação com as funções tradicionais.

Exemplo 1: Função Tradicional


        function soma(a, b) {
            return a + b;
        }
        
        console.log(soma(2, 3)); // Saída: 5

Exemplo 2: Arrow Function


        const soma = (a, b) => a + b;
        
        console.log(soma(2, 3)); // Saída: 5

Neste exemplo, a função `soma` foi reescrita como uma Arrow Function, tornando o código mais conciso.
