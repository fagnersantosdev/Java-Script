Try e Catch

O que é Try Catch?

Em português, try significa "tente" e catch significa "capture". Essa estrutura é o grande sistema de segurança do JavaScript para lidar com o imprevisível.

Quando você faz uma requisição para a internet (como usando o fetch), muita coisa foge do seu controle: a rede do usuário pode cair, o servidor da API pode desligar para manutenção ou o link pode estar errado. O try/catch serve exatamente para impedir que esses imprevistos destruam o seu aplicativo.

Por que ele é importante no dia a dia?

  • Evita o colapso (Crash): Sem ele, um erro na comunicação com a API faz o JavaScript entrar em pânico e parar de ler o resto do código. Isso geralmente resulta em uma tela em branco para o usuário.
  • Mensagens amigáveis: Ele permite que você assuma o controle da falha e mostre um aviso educado na tela (ex: "Verifique sua conexão com a internet"), em vez de deixar o sistema congelado.
  • Rastreio de bugs: A variável de erro que vai dentro dos parênteses do catch(erro) guarda os detalhes técnicos exatos do que falhou, ajudando você (o desenvolvedor) a consertar o problema rapidamente nos bastidores.

Como funciona na prática?

Pense no try/catch como pedir para um amigo ir à padaria comprar pão:

  • try: Você diz "Tente ir lá, pedir o pão e pagar". É o cenário ideal. Se der tudo certo, o código segue normalmente.
  • catch: Se a padaria estiver fechada ou o pão tiver acabado, em vez de o seu amigo ficar paralisado na calçada sem saber o que fazer, ele entra no "modo de emergência" (o catch), captura o problema e volta para te avisar que deu errado.

Veja a estrutura como fica:

        
            async function carregarProdutos() {
            try {
                // O código tenta executar o caminho feliz, linha por linha
                const resposta = await fetch("https://api-falsa.com/produtos");
                const produtos = await resposta.json();
                console.log("Sucesso! Aqui estão os produtos:", produtos);
                
            } catch (erro) {
                // Se QUALQUER linha do 'try' falhar, o JavaScript abandona o 'try' 
                // e pula imediatamente para cá, salvando o programa.
                console.log("Ops! Não conseguimos carregar a vitrine agora.");
                console.error("Detalhes técnicos para o dev:", erro);
            }
        }
