Funções Assíncronas

No JavaScript, algumas coisas demoram para acontecer (ex: buscar dados em um banco ou em uma API).
Se o código parasse para esperar, a tela do usuário ficaria travada. Por isso, usamos o conceito assíncrono: o código dispara o pedido e continua rodando o resto; quando a resposta chega, ele avisa.
A evolução disso foi: Callbacks ➔ Promises ➔ Async/Await. Hoje, usamos predominantemente o async/await por ser muito mais fácil de ler

Exemplo de Função Assíncrona

        
        async function fetchData() {
            try {
                const response = await fetch('https://api.example.com/data');
                const data = await response.json();
                console.log(data);
            } catch (error) {
                console.error('Erro ao buscar dados:', error);
            }
        }

        fetchData();

Junto com isso, temos o fetch(), que é a função nativa do navegador para fazer requisições a APIs.

Exemplo de Fetch

        
            async function buscarUsuarios() {
            const resposta = await fetch("https://jsonplaceholder.typicode.com/users");
            const dados = await resposta.json();
            console.log(dados);
        }
        //Note o uso da palavra `async` antes da função e `await` antes das operações que "demoram".

O fetch() retorna uma Promise, que é um objeto que representa a eventual conclusão (ou falha) de uma operação assíncrona.
A Promise pode estar em três estados: pending (pendente), fulfilled (cumprida) ou rejected (rejeitada).
O await é usado para esperar a resolução da Promise antes de continuar a execução do código.
