Set em JavaScript

O que é SET e JavaScript?

Em resumo, um Set (que traduzimos como "Conjunto") é bem parecido com um Array (uma lista de itens), mas com uma regra de ouro imutável: ele nunca aceita valores duplicados.

Se você tentar adicionar um valor que já existe lá dentro, o JavaScript simplesmente ignora a sua tentativa, silenciosamente.

Como funciona na prática?

        
            const meuSet = new Set();

            // Adicionando valores
            meuSet.add("Maçã");
            meuSet.add("Banana");
            meuSet.add("Maçã"); // Tentei adicionar Maçã de novo!

            console.log(meuSet); 
            // Resultado: Set { 'Maçã', 'Banana' } -> Ele ignorou a segunda "Maçã"!

Principais métodos do Set (em vez do push e pop dos arrays):

  • add(valor): Adiciona um item.
  • delete(valor): Remove um item específico (ex: meuSet.delete("Banana")).
  • has(valor): Retorna true ou false se o item existir lá dentro. É muito mais rápido que o includes() do Array.
  • size: Retorna o tamanho do Set (é o equivalente ao length do Array). Ex: meuSet.size.

O "Truque de Mágica" do Set + Spread Operator

Lembra do Spread Operator (...)? Olha que união perfeita:

        
            // Temos um array cheio de categorias repetidas vindo do banco de dados
            const categoriasRepetidas = ["Eletrônicos", "Roupas", "Eletrônicos", "Livros", "Roupas"];

            // 1. Passamos o array para dentro do new Set() -> Ele remove as duplicatas na hora!
            // 2. Usamos o Spread (...) para espalhar esse Set limpo de volta para dentro de um Array []
            const categoriasUnicas = [...new Set(categoriasRepetidas)];

            console.log(categoriasUnicas); 
            // Resultado: ["Eletrônicos", "Roupas", "Livros"]

É a forma mais elegante, moderna e rápida de limpar listas no JavaScript!
