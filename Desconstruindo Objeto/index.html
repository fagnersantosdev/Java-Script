Descontruindo um Objeto

A desestruturação de objetos em JavaScript permite extrair propriedades de um objeto e atribuí-los a variáveis individuais de forma concisa.

Exemplo de desestruturação de um objeto

        
            const pessoa = {
                nome: "João",
                idade: 30,
                cidade: "São Paulo"
            };

            const { nome, idade, cidade } = pessoa;

            console.log(nome); // Resultado: João
            console.log(idade); // Resultado: 30
            console.log(cidade); // Resultado: São Paulo

No exemplo acima, estamos desestruturando o objeto pessoa e atribuindo suas propriedades às variáveis correspondentes.
