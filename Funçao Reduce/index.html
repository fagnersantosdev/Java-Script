Função Reduce

O que o Reduce faz?

Enquanto o map devolve um array do mesmo tamanho, e o filter devolve um array menor, o reduce serve para reduzir uma lista inteira a um ÚNICO valor.

Esse "único valor" pode ser a soma de todos os números, uma string gigante juntando tudo, ou até um objeto novo. O uso mais clássico (e o mais fácil para entender) é o carrinho de compras: você tem uma lista de preços e quer reduzi-la ao valor total que o cliente vai pagar.

A anatomia do Reduce

Para ele funcionar, ele precisa de dois ingredientes principais:

  1. Callback Function: Que recebe um Acumulador (a "caixa" onde o resultado vai se acumulando) e o Item Atual (o elemento da lista que ele está lendo naquela hora).
  2. Valor Inicial: O número (ou objeto/array) com o qual o acumulador vai começar.

Veja na prática:

        
            const precos = [10, 20, 30];

            // O "0" lá no final é o valorInicial. O 'acumulador' começa valendo 0.
            const total = precos.reduce((acumulador, precoAtual) => {
                return acumulador + precoAtual;
            }, 0);

            console.log(total); // Resultado: 60

O passo a passo invisível que ele faz:

        
            // Rodada 1: acumulador = 0, precoAtual = 10 => acumulador + precoAtual = 10
            // Rodada 2: acumulador = 10, precoAtual = 20 => acumulador + precoAtual = 30
            // Rodada 3: acumulador = 30, precoAtual = 30 => acumulador + precoAtual = 60
