Manipulação de String

Quando recebemos dados do usuário (como um formulário), os textos costumam vir bagunçados. O documento lista os métodos mais úteis para tratar isso:

  • trim(): Remove espaços em branco sobrando no início e no final do texto. Excelente para limpar campos de login.
  • toUpperCase() / toLowerCase(): toUpperCase() / toLowerCase(): Transforma o texto todo em maiúsculas ou todo em minúsculas.
  • replace(): Busca uma palavra no texto e substitui por outra.
  • includes():includes(): Verifica se um determinado trecho existe dentro da string (retorna true ou false).
  • split(): "Corta" a string com base em um separador (como uma vírgula ou espaço) e devolve um array com os pedaços.
  • join(): É o inverso do split. Pega um array e junta tudo em uma única string.
